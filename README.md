# Cybershield
An interactive C++ social engineering attack simulator for cybersecurity awareness.

**CyberShield** is a menu-driven C++ mini project designed to improve cybersecurity awareness by simulating common social engineering attacks in a safe, educational environment.

Users interact with simulated phishing emails, suspicious messages, and impersonation attempts, receive feedback on their decisions, and view their cybersecurity awareness score.

## 🎯 Objectives
- Understand common social engineering techniques.
- Identify suspicious emails and messages.
- Learn safe responses to impersonation attempts.
- Evaluate cybersecurity awareness through interactive questions.
- Apply Object-Oriented Programming (OOP) concepts using C++.

## ✨ Features
- 📧 Phishing email simulation
- 💬 Suspicious message simulation
- 🔐 Impersonation scenario
- ✅ Instant feedback on answers
- 📊 Score and percentage calculation
- 🖥️ Interactive console menu

## 🚀 How to Run
### Using Visual Studio
1. Clone or download this repository.
2. Open `Cybershield.cpp` in Visual Studio.
3. Create or open a C++ Console project and add the source file if needed.
4. Build the project.
5. Run the program and select an option from the menu.

### Using g++

If g++ is installed, open a terminal in the folder containing the source file and run:

```bash
g++ Cybershield.cpp -o CyberShield
```

On Windows, execute:

```bash
CyberShield.exe
```

## 📈 Scoring System

The program tracks the number of correct answers and attempted scenarios. It calculates the awareness score as:

**Awareness Score = (Correct Answers / Questions Attempted) × 100**

The program displays feedback based on the score.
